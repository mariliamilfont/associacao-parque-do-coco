# Associação Parque do Cocó

Frontend do projeto de extensão 4, desenvolvido para a ONG Associação Parque do Cocó.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Desenvolvimento

Instale as dependências e inicie o servidor local:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Validação

```bash
npm run lint
npm run build
```
